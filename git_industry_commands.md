# Industry-Level Git & GitHub Commands Practice

## 1. Git Configuration Commands
# 1. git config --global user.name
- Syntax:
        git config --global user.name "Name"
- Purpose:
        it sets the author name for all git commits
- Example:
        git config --global user.name "Ram"

## 2.Repository setup commands
these commands are used to create and copy repositories

# 1.git init
- Syntax:
   git init
- Purpose:
    git init initializes a new git repository in the current folder.
    it converts a normal folder into git tracked folder.
    After running this command:
        A hidden folder called .git is created
        Git starts tracking changes
        You can now use all Git commands
- Example:
        git init
- Screenshot:
        <img src="C:\Users\raman\OneDrive\Pictures\Screenshots 1\Screenshot 2026-03-31 181704.png">

# 2.git clone
- Syntax:
        git clone <repository-url>
- Purpose:
    To copy a remote Git repository to your local machine.
- Example:
    git clone https://github.com/Ramdas-220155/AI-Resume-Screening-System.git
- Screenshot:
    <img src ="C:\Users\raman\OneDrive\Pictures\Screenshots 1\Screenshot 2026-03-31 182924.png" >

# 3.git clone --branch
- Syntax:
        git clone --branch <branch-name> <repo-url>
        or
        git clone -b <branch-name> <repo-url>
- Purpose:
    To clone a specific branch instead of the default branch.
- Example:
        git clone --branch finalone https://github.com/Ramdas-220155/AI-Resume-Screening-System.git
- Screenshot:
        <img src = "C:\Users\raman\OneDrive\Pictures\Screenshots 1\Screenshot 2026-03-31 184047.png">

# 4.git clone --depth
- Syntax:
        git clone --depth <number> <repo-url>
- Purpose:
    To clone a repository with limited commit history for faster performance.
- Example:
     git clone --depth 1 https://github.com/Ramdas-220155/AI-Resume-Screening-System.git
